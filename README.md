A small island flight game in plain JavaScript: take off from the coastal
runway, thread rings over the hills, drop cargo on the harbour target, sweep
low coast checkpoints, and bring the aeroplane home for a graded landing.
Throttle discipline, stalls, fuel, wind and hull damage all matter.

## Play it

```sh
node serve.ts
```

Then open the local address it prints in a desktop browser. Arrow keys fly,
W/S work the throttle, A/D nudge the rudder, holding the mouse steers, the
wheel trims throttle, Space drops cargo, C swaps chase and cockpit cameras,
and P pauses.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
